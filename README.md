# Nebriviajes


## Cómo ejecutar (IMPORTANTE)

No abras el `index.html` haciendo doble click (pantalla en blanco). Este proyecto usa **Vite**, así que debes arrancar el servidor.

### Frontend
```bash
cd NebriviajesFinal/frontend
npm install
npm run dev
```

### Backend
```bash
cd NebriviajesFinal/backend
npm install
npm run dev
```

- Frontend: normalmente en `http://localhost:5173`
- Backend: normalmente en `http://localhost:3000` (o el puerto configurado)
